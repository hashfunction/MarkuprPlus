2. `02-one-mark-one-issue.png` — one mark becomes one AI-ready issue
3. `03-talk-through-bugs.png` — narration and on-device Whisper transcription
4. `04-choose-ai-analysis.png` — Ollama, LM Studio, Anthropic API, and Local Rules
5. `05-local-control.png` — local-first storage and user-selected exports
