# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Enforcement

The project does not yet publish a verified private conduct mailbox. For non-sensitive conduct contact, use the public [Contact issue route](https://github.com/hashfunction/MarkuprPlus/issues/new). Do not include private identities, sensitive evidence, or security details in a public issue; open only a minimal request for a private channel and wait for current-project maintainers to arrange one.

Maintainers will review reports in good faith, protect reporter privacy where practical, and apply proportionate corrective action. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).
